# MetaCRISPR

## AI-Powered CRISPR Guide RNA Design Framework

MetaCRISPR is a hybrid AI-driven framework for CRISPR guide RNA (gRNA) design and evaluation that integrates:

- DNABERT-2 for genomic sequence understanding
- Prototypical Few-Shot Learning for efficacy prediction
- Physics-Informed Neural Networks (PINNs) for biological constraint modeling
- SHAP Explainable AI for model interpretability

The system generates, evaluates, and ranks candidate gRNAs based on efficacy, specificity, thermodynamic stability, and off-target risk.

---

## Project Overview

Genome editing using CRISPR-Cas systems requires highly efficient and specific guide RNAs. Traditional computational approaches often struggle to balance efficacy, specificity, and biological constraints simultaneously.

MetaCRISPR addresses this challenge by combining transformer-based sequence representations, physics-guided learning, and explainable AI into a unified framework for intelligent gRNA design.
